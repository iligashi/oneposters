# Security

Please report suspected security vulnerabilities privately to [hello@oneposters.studio](mailto:hello@oneposters.studio). Include the affected URL or component, a concise impact description, and steps to reproduce. Do not include customer personal data in a report.

Please avoid accessing, changing, or deleting data that is not yours, and stop testing once you have demonstrated the issue. This project does not currently publish a bug bounty or guaranteed response-time commitment.
